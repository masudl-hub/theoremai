# v0.3.0

## Summary

This is the first release of Theorem on npm, as `@theoremjs/agents` and `@theoremjs/react`. On JSR, `@theoremjs/agents` 0.3.0 follows `@theoremai/agents` 2.0.1. Profiles can now pick the bundled egress checks, and function tools can sign in to a service for the user.

## What's New

- **React package.** `@theoremjs/react` is new. `useTheoremChat` gives you the chat state and actions. It renders nothing. `TheoremChat`, `TheoremHost`, and `TheoremDecision` from `@theoremjs/react/ui` are ready-made UIs built on the hooks. `createTheoremHandler` from `@theoremjs/react/server` serves one profile to the chat on one route. `createTheoremDecisionHandler` and `createTheoremHostHandler` do the same for decision and host profiles.
- **Kernel scopes.** `createKernelScope` from `@theoremjs/agents` gives you profile, tool, and schema registries that no other scope sees. Use it when a host registers profiles per request. The global functions, such as `registerProfile` and `runTurn`, use `defaultKernelScope`.
- **Turn events as schemas.** `turnEventSchema`, `TURN_EVENT_SCHEMAS`, `toolGateSchema`, and `turnHistoryMessageSchema` from `@theoremjs/agents` parse turn events and history that cross the network. `TurnEventOf<'done'>` names one event kind. The package exports its own `z`. Build your tool schemas with it, because two copies of zod do not mix.
- **Evals over traces.** `@theoremjs/agents/evals` runs a suite of cases against any profile. It grades each trial from its trace. Load cases with `loadSuite` and run them with `runSuite`. Grade with code graders, such as `outcome`, `toolTrajectory`, `budget`, and `guardrail`, or with a model through `judge`. `phoenixAnnotations` from `@theoremjs/agents/observability/phoenix` turns the results into Phoenix span annotations.
- **Bundled egress checks in the profile.** Set `guardrails.egress.checks` to `true`, or to an `EgressChecks` object that switches each check: `sensitive` (by group), `boundary`, `injection`, `images`, and `links`. A URL check takes `hosts` and `fromTools`. To add your own regex rules, use `egressPolicy` from `@theoremjs/agents/guardrails`. Compile the rules at build time with `compileEgressRules` from `@theoremjs/agents/guardrails/compile`, or with the `agents egress-compile` command. The stream then holds back only text that could still become a match.
- **System prompt leak checks.** With the canary on, a reply that repeats 12 consecutive words of the system prompt is a leak (`guardrails.promptEcho`, default on). `identity.system` takes a list of parts. A `{ private: '…' }` part holds private text. The plain parts beside it are shareable, and the echo check reads only the private text. The canary scan also reads the token reversed, in ROT13, spelled out, as character codes, and in base64. `scanTextForPromptEcho` from `@theoremjs/agents/guardrails` runs the echo check in your own enforcer.
- **Named key slots and a fallback key.** A key slot is any name that matches `KEY_SLOT_NAME`. Name a `fallbackKey` on the profile or on a model. When the provider refuses the key for quota, the call retries once with the fallback slot. `createProvider`, `runSession`, and `runDecision` read every provider's key from one `vault`.
- **Sign-in for function tools.** A function tool can declare `auth`, as HTTP and MCP tools do. The handler gets `ctx.signedInFetch`, which sends the credential only to the service's own origin. The handler never holds the credential. Pass credentials as a `ToolCredentialSource`. The kernel reads a slot only when a tool that signs in runs. From `@theoremjs/agents/kernel`:
  - `memoryCredentialSource` wraps a plain record as a source.
  - `sealSecret` and `openSecret` encrypt a credential that you store.
  - `CredentialRefusedError` lets a handler that catches its own errors rethrow a refused credential.
- **MCP servers that need a session.** Calls stay stateless. When a server answers 400 and names `Mcp-Session-Id`, the kernel opens a session, keeps it in memory, and reuses it. A `structuredContent` that does not match the tool's output schema is a tool warning, and the call uses the text content. MCP results keep their structured content and media.
- **Tool sources and activity labels.** A tool can declare `sources(output)`. On a completed call, the kernel emits a `citation` event with the call's id. `labels.activity` and `labels.activityPast` take placeholders, such as `{input.city}`. The kernel fills them from each call's input and output.
- **An agent can compact its own history.** `models.*.compaction.profile` is now optional. Without it, the agent compacts with its own instructions and model, and no tools. Image and speech profiles can compact. For `timing: 'after'`, call `compactHistory` with what `done.compaction` carried.
- **Image output settings.** An image profile can pin `image.resolution`, `image.quality`, `image.background`, `image.n`, `image.seed`, `image.outputCompression`, and `image.references` (reference images sent on every turn).
- **Live sessions.** `LiveSession.sendContext` sends text the model reads as background, without a reply. `LiveSession.answerToolCall` settles a call whose body ran in another process. `runSession` takes `gateTtlMs`, the time a gated call waits for its `decision` (default 30 minutes). With `signInGate: 'answer'`, the model reads a sign-in gate's pending note at once. Use it when the user signs in outside the session.
- **Surfaces.** `@theoremjs/agents/surface` lets an agent see and work in a client's screen. A page mounts a surface (nodes with fields and actions) on a runtime from `createSurfaceRuntime`. `surfaceTools` gives the model two tools, `look` and `act`. Secrets reach the model only as cards.
- **Google presets.** `googleEfforts` from `@theoremjs/agents/presets/google` builds a Gemini binding's `efforts`. It refuses levels the model cannot take. `googleBindingViolation` checks a binding against the Google model rules. `GOOGLE_NO_THINKING_API_IDS`, `GOOGLE_SINGLE_TURN_API_IDS`, and `GOOGLE_FREE_TIER_GROUNDING` name the models each rule covers.

## What's Fixed

- `allowContinue: []` let every stop kind continue. It now continues nothing, as `autoContinue: []` auto-continues nothing.
- `outputs.streaming.mode: 'buffered'` reached only Google Interactions. OpenRouter and local chat now make one non-streaming call too.
- When Google refused an API key, the user read "that isn't something the assistant can do". It is now an `auth` error. An overloaded or failing Google model inside a stream is now `unavailable`, not a bad response.
- Egress treated IP addresses in a reply as secrets. The `sensitive` check now leaves the `network` group off by default. Inbound sanitization still redacts addresses.
- An image turn on Google Interactions that returned only text passed as complete. It is now a `bad_response` error.
- A failed compaction could replace the history with a hollow summary. The history now stays whole within `maxTokens`, and the next turn tries again. Over `maxTokens`, the kernel drops the part it could not compact. The compaction request also keeps who said what.
- Gemini Interactions and Live accepted the effort levels `none`, `xhigh`, and `max` at registration, and the API then refused them. Registration now refuses them.
- A Google model with no key slot passed registration and failed on its first turn. Registration now refuses it.
- A media limit of 0 was read as unset, and negative or fractional limits passed. Limits must now be positive integers.
- Google refused a tool result in host history that had no name. The adapter now fills the name from the matching call.
- Stateless MCP calls left out the client capabilities and the `Mcp-Method` and `Mcp-Name` headers. Servers on the 2026-07-28 revision refused them. The calls now carry them.

## Breaking Changes

- **The package is `@theoremjs/agents`.** `@theoremai/agents` 2.0.1 was on JSR only. Version numbers start again at 0.3.0. To upgrade, install the new package and change every import:

  ```sh
  deno add jsr:@theoremjs/agents
  # or
  npm install @theoremjs/agents zod
  ```

  ```ts
  // Before
  import { defineProfile, runTurn } from 'jsr:@theoremai/agents';
  // After
  import { defineProfile, runTurn } from '@theoremjs/agents';
  ```

  The subpaths keep their names: `@theoremai/agents/kernel` becomes `@theoremjs/agents/kernel`, and so on.

- **One key vault for every provider.** `createProvider` and `runSession` take the vault as `vault`. `gemini` keeps only the Google settings. `OpenAiGatewayConfig` has no `apiKey` or `vault`. `runDecision` takes `vault` in place of `apiKey` and `keyVault`.

  ```ts
  // Before
  createProvider(profile, { gemini: { vault }, openAiGateway: { apiKey } });
  runSession(req, { gemini: { vault } });
  // After
  createProvider(profile, { vault });
  runSession(req, { vault });
  ```

  Every model that is not `local` must name a slot in `models.*.key` or the profile `key`. This includes OpenRouter models. A `local` model needs `createProvider(profile, { vault, local: { baseUrl } })`. `baseUrl` is required, and `DEFAULT_LOCAL_BASE_URL` is gone.

- **Key slots are yours to name.** The fixed slots `slotA`, `slotB`, `slotC`, and `paid` are gone, with `KEY_SLOTS`, `OVERFLOW_KEY_SLOTS`, and `OverflowKeySlot`. A quota refusal no longer moves to the `paid` slot on its own. To keep that, name the slot in `fallbackKey`. Use `KEY_SLOT_NAME` or `isKeySlotName` to check a name.
- **`persistViaInteractionId` is required on every `geminiInteractions` binding.** `true` chains each step and turn on Google's stored interaction. `false` sends the host's history plus this turn's steps on every call. `true` with `store: false` fails at registration.
- **Profile fields that changed.**
  - `image.size` is now `image.resolution`. `GOOGLE_IMAGE_SIZES` is now `GOOGLE_IMAGE_RESOLUTIONS`.
  - `live.proactiveAudio` is gone. Google's Live endpoint refused it and closed the session.
  - `live.vad.startSensitivity` takes only `START_SENSITIVITY_*` values. `live.vad.endSensitivity` takes only `END_SENSITIVITY_*` values. `LIVE_SPEECH_SENSITIVITIES` is now `LIVE_START_SENSITIVITIES` and `LIVE_END_SENSITIVITIES`.
  - `outputs.structured` and `outputs.validation` apply to text profiles only.
  - `guardrails.egress` takes `enforce` or `checks`, never both.
  - `guardrails.egress.holdback` applies only to your own `enforce`. With `standardEgressEnforce`, `checks`, or an `egressPolicy`, it fails `defineProfile`.
  - A host profile refuses `guardrails.taint`. It never ran there.
  - A decision profile's model needs `protocol: 'decision'` and `provider: 'typesafe'` or `'openrouter'`. Its `retry` field is gone.
- **A turn takes only the slots its profile declares.** `resolveTurn` rejects a slot the profile does not declare, or a value outside its choices. `defineProfile` rejects an `outputs.structured.by` that names an undeclared slot.
- **Turn events are a union by `type`.** `TurnEvent` is now a discriminated union. Check `event.type` before you read a field.
  - Sources moved from `grounding.sources` to `citation` events.
  - `GroundingSource` is now `Source`, and `ProviderEvidenceEvent` is now `ProviderEvidence`.
  - A custom `ModelProvider` yields `ProviderEvent` from `complete`.
  - In a decision result, a score's `legend` maps each level to text, not to a number.
- **Tool credentials come from a source.** `credentials` on `TurnRequest`, `SessionRequest`, and `InvokeToolRequest` is now a `ToolCredentialSource`, not a record. Wrap an existing record:

  ```ts
  // Before
  runTurn({ ...req, credentials: { github: credential } }, provider);
  // After
  import { memoryCredentialSource } from '@theoremjs/agents/kernel';
  runTurn({ ...req, credentials: memoryCredentialSource({ github: credential }) }, provider);
  ```

  `LiveSession.executeTool` names the call by `callId` only. It answers a gate with `decision` or `secret` in place of `resume`.

- **Stricter leak checks.** These change what your users see:
  - Any 16 characters of the canary now end the turn. Before, the whole token was needed.
  - With the canary on, a reply that repeats 12 words of the system prompt now stops. If the agent must quote text from its system prompt word for word, set `guardrails.promptEcho: false`. You can also put the private instructions in a `{ private }` part, so the quoted text beside it is shareable.
  - A host egress policy can no longer release a canary hit.
  - A guarded Live profile plays each spoken reply after its transcript passes the checks, not while it streams. Hosts get output transcript events even when `live.transcription.output` is not set.
- **Removed and moved exports.**
  - `jsonlSink` and `JsonlSinkOptions` moved to `@theoremjs/agents/observability/jsonl`. `jsonlDestination`, `isJsonlTraceDestination`, `JsonlTraceDestination`, and `TraceDestination` are gone. `registerTraceDestination` takes a `TraceSink`:

    ```ts
    // Before
    import { jsonlDestination, registerTraceDestination } from 'jsr:@theoremai/agents';
    registerTraceDestination('local', jsonlDestination('./traces'));
    // After
    import { registerTraceDestination } from '@theoremjs/agents';
    import { jsonlSink } from '@theoremjs/agents/observability/jsonl';
    registerTraceDestination('local', jsonlSink('./traces'));
    ```

  - `listBuiltinIds` and `listFunctionIds` are gone. Filter `listTools()` by `type`.
  - `parseToolGate` and `parseAwaitingUserInput` are gone. Use `toolGateSchema` and `awaitingUserInputSchema`.
  - `speechFormatsForProtocol`, `isSpeechFormatAllowedForProtocol`, and `coerceSpeechFormat` are gone. `GOOGLE_SPEECH_FORMATS` names what Google speech takes.
  - `GeminiTransport` is now `GeminiOptions`, without `vault`.
  - `ToolPause` is gone from `@theoremjs/agents/kernel`.

## Notes

- `@theoremjs/react` 0.3.0 is its first release. Its peers are `@theoremjs/agents` ^0.3.0, `react` ^19, `react-dom` ^19, `@stylexjs/stylex` 0.19.0, `@astryxdesign/core` 0.6.3, and `@astryxdesign/theme-neutral` 0.6.3.
- Both packages need Node.js 20 or later. `@theoremjs/agents` needs `zod` ^4.1.8 as a peer.
- New subpaths:
  - `@theoremjs/agents/evals`
  - `@theoremjs/agents/surface`
  - `@theoremjs/agents/interface`
  - `@theoremjs/agents/guardrails/compile`
  - `@theoremjs/agents/observability/jsonl`
  - `@theoremjs/agents/observability/phoenix`
- The egress rule compiler loads only through `@theoremjs/agents/guardrails/compile` and the `agents egress-compile` command.
- `@theoremai/agents` 2.0.0 and 2.0.1 stay on JSR. New versions come out as `@theoremjs/agents`.
